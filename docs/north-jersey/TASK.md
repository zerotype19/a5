# North Jersey expansion

Owner direction: keep expanding; cover all of North New Jersey. Continue the established conditional-request publication model and prior release authorization. Working scope is Bergen, Essex, Hudson, Morris, Passaic, Sussex, Union and Warren counties; the owner has been asked whether to include Hunterdon and Somerset.

## Deliverable

A county-organized North Jersey directory with every municipality discoverable, eight individually authored county hubs, existing service/problem/guide connections, and contextual request links. Existing town/service URLs remain stable. New municipalities are request geography only; vendor coverage is checked individually and is not created by the registry seed.

County hubs use the existing CORE record type, explicitly allowlisted county slugs and /home-services/county/[county] routes. This adds a geographic browse level without a new database content enum or an automatic town/service/problem matrix. Municipality rows remain distinct from county content records. Hundreds of town-name-swapped articles are not a completion criterion; every municipality has a useful directory entry and request path, while existing authored town pages remain linked.

Admin municipality selection must remain navigable at regional scale. The public footer/homepage use county navigation rather than hundreds of links. Sources verify municipal identity, including same-name municipalities and borough/township distinctions. No inferred ZIP mapping, provider activation, outreach, spending or new services.

## Acceptance

- Complete county-by-county municipality inventory sourced from official records; preserve legacy A5 IDs and Chatham's existing shared content route without misclassifying the two municipalities.
- Canonical, indexable, source-backed county records with direct answers and useful service/project links.
- Server-rendered municipality directory with accessible search/filter and county grouping, compact mobile layout, no emojis.
- Safe admin selection and explicit request availability notices.
- Versioned publication, exact manifest, baseline backup, tests/builds, responsive review, production deploy and live sitemap checks.
