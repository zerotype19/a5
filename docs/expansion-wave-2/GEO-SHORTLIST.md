## Proposed rollout shape

1. Complete the 22 existing-page revisions and the four new problem drafts without waiting for paid-ad decisions.
2. Select the first two or three new municipalities from owner/provider input. Prepare one useful town hub for each, then only the service/town pages with confirmed fulfillment and distinct homeowner value.
3. Link each new local page to a service hub, town hub, relevant canonical problem pages and a planning guide. Keep problem articles canonical across towns rather than cloning them for every location.
4. Validate exact municipal names and intake matching; snapshot existing content before approved publication. Inspect canonicals, sitemap, source links, mobile layout and contextual request links afterward.
5. Track indexed URLs, query/page impressions, requests, qualified leads and mature outcomes by the new cohort. Scale the next batch on evidence; do not call publication a lead result.
